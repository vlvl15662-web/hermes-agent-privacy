HermesAgent 개인정보처리방침

시행일: 2026-10-09

1. 대상

HermesAgent(이하 "본 프로그램")는 운영자 본인의 Google 계정에만 연결해 쓰는 개인용 프로그램입니다. 운영자 외 다른 사람의 Google 계정 데이터는 다루지 않습니다.

2. 접근하는 Google 사용자 데이터

  • Google 캘린더: 일정 읽기·생성·수정
  • Gmail: 메일 읽기·라벨 정리, 운영자가 지시한 메일 발송
  • Google Drive·Docs·Sheets: 운영자 문서 읽기·작성
  • Google 연락처: 읽기 전용 조회

3. 사용 목적

위 데이터는 운영자 본인의 일정·메일·문서 업무를 대신 처리하는 데만 씁니다. 광고, 프로필 분석, 판매, 제3자 제공에 쓰지 않습니다.

4. 저장과 보관

  • 로그인 토큰과 처리 결과는 운영자 본인 PC에만 저장합니다. 별도 서버에 올리지 않습니다.
  • 작업 처리에 필요한 범위에서만 내용을 일시적으로 읽고, 운영자 업무 기록에 필요한 요약만 운영자 PC에 남깁니다.

5. 제3자 제공과 AI 처리

Google 사용자 데이터를 판매하거나 광고 목적으로 제3자에게 넘기지 않습니다. 운영자가 지시한 작업을 처리하려고 운영자가 계약한 AI 모델 제공자에 필요한 내용 일부를 보낼 수 있으며, 이는 운영자 본인의 업무 처리 목적에 한정됩니다.

6. Google API 서비스 사용자 데이터 정책 준수

본 프로그램이 Google API로 받은 정보의 사용과 다른 앱으로의 전송은 제한적 사용(Limited Use) 요구사항을 포함한 Google API Services User Data Policy를 따릅니다.

7. 접근 철회와 삭제

운영자는 Google 계정 권한 페이지에서 언제든 본 프로그램의 접근을 철회할 수 있습니다. 철회하면 PC에 저장된 토큰은 더 이상 쓰이지 않으며 운영자가 삭제합니다.

8. 문의

문의는 Google 동의 화면에 표시된 사용자 지원 이메일로 받습니다.
